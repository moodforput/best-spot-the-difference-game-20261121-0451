LUMEN & LARK — a complete, original spot-the-difference game: three hand-painted procedural scenes (Harbor Dusk, Night Market, Clockmaker's Attic), 5 / 7 / 10 differences each, hints, combo scoring, timer pressure and synthesized sound. Fully offline — vanilla canvas, no libraries, no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play with mouse and keyboard (H hint, M mute, R restart, 1–3 levels).
